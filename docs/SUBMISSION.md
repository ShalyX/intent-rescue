## Proposed project description

OSIALI is an incident-investigation desk for stalled NEAR Intents swaps. Users can look up a deposit address or Explorer transaction, reconstruct the source-to-destination lifecycle, inspect source-attributed evidence, and identify the first unresolved step. OSIALI distinguishes provider and Explorer snapshots from user-supplied reports and independently verified terminal evidence, fails closed on ambiguous or conflicting data, and recommends the next safe check. Users can export a structured, support-ready JSON case file with identifiers, evidence links, provenance, and an escalation summary. OSIALI uses read-only NEAR Intents 1Click and Explorer data; it does not move funds, execute refunds, or claim settlement finality without evidence.
