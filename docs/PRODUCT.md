# Product purpose

OSIALI helps a swap user, NEAR Intents integrator or support operator investigate a delayed, failed, incomplete or unrefunded swap.

The workflow is: enter a supported identifier or matching evidence payload; reconstruct source deposit, 1Click intake, intent/solver, delivery or refund; identify the unresolved evidence boundary; recommend a conservative next step; export a support-ready case.

Core requirements are multi-identifier intake with manual fallback, lifecycle reconstruction, deterministic classification, evidence provenance, bounded next-action guidance, portable export and available explorer links.

OSIALI is not a wallet, swap executor, refund service, chatbot or generic block explorer. It does not custody funds, guarantee recovery, infer root cause from missing evidence or execute financial actions. Historical snapshots and manually supplied reports must remain distinguishable from independent verification.
